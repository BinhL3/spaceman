# Spaceman 0.1.2

- Adds workspace-wide Fullscreen Layout with `Option+Shift+F`, preserving the split layout for an
  instant return.
- Adds `Option+backtick` to cycle tiled windows in stable workspace order.
- Shows Fullscreen Layout as a filled workspace glyph in the menu bar and exits the mode when its
  final tiled window leaves.
- Makes `Option+/` leave Fullscreen Layout and apply the next split axis immediately.
- Reliably expands surviving windows after a transient window from another running app closes.
- Preserves Fullscreen Layout, focus, logical slots, and nested layout through workspace switches,
  native Ghostty tab replacement, and restarts.
