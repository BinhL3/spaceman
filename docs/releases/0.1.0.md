# Spaceman 0.1.0

The first installable Spaceman preview for Apple silicon Macs.

- Fast, flash-resistant switching across ten workspaces.
- Per-display workspace lanes and previous-workspace switching.
- Nested weighted layouts, directional focus and movement, resize, balance, and maximize controls.
- Conservative native-tab replacement that preserves logical window identity.
- Durable parked-window recovery across pause, quit, external termination, restart, and updates.
- Compact Settings for Accessibility, Launch at Login, and signed Sparkle updates.
- Developer ID signing, Apple notarization, stapling, SHA-256 checksums, and signed R2 appcasts.

This remains an experimental arm64 preview. Clean-machine qualification, broader macOS validation,
x86_64 support, and a product demo are still outstanding.
